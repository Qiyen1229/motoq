# MotoQ — 私有汽機車管理

自架、可多使用者（含管理後台）的車輛管理網站：汽車／機車／重機，燃油、純電、油電皆可。
所有資料存在本機 SQLite 與資料目錄，單據圖片在伺服器端壓縮並移除 EXIF，不經任何第三方服務。

- 設計文件：[docs/architecture.md](docs/architecture.md)
- 技術：React + Vite + TypeScript + Tailwind（PWA、Recharts）／FastAPI + SQLAlchemy + Alembic + APScheduler／SQLite（WAL）

## 功能

| 區塊 | 內容 |
|---|---|
| 車輛 | 汽車、機車、重機；燃油／純電／油電（油電僅限汽車）；多車切換；儀表更換不中斷里程 |
| 能源 | 加油／充電記錄，三項填兩項自動算第三項、單次里程（trip）、里程倒退確認；油耗／電耗、每公里費用、趨勢圖、異常下降警示 |
| 保養 | 依車種套用範本或自訂；**里程或時間先到先提醒**；以近 90 天里程預測到期日；進廠明細即維修履歷 |
| 稅費 | 牌照稅、燃料費、強制險、任意險、驗車、排氣檢驗；30/7/1 天（可自訂）狀態標示；一鍵標記已繳並建立下一期 |
| 罰單等 | 罰單（手動、CSV 匯入、預留查詢介面）、停車／過路費等支出、etag 儲值與餘額 |
| 單據 | 對加油、保養、稅費、罰單附上照片（壓縮、移除 EXIF）；**不做 OCR，由你手動填寫** |
| 報表 | 年度持有成本與每公里成本（可手動存檔、每年 12/31 自動產生）、兩車以上比較、維修履歷 PDF |
| 帳號 | 註冊（第一位為管理員）、登入限流、管理後台（使用者、稽核紀錄、工作階段、安全設定） |
| 資料 | JSON／CSV 匯出、JSON 匯入（自動快照）、備份腳本 |
| 油價 | 直接取用政府資料開放平臺的「中油主產品牌價」，首頁有人查看且資料過舊時自動更新（另有每 3 小時排程）；加油時依油品與加油站自動帶入單價 |
| 加油站 | 中油、台塑、全國、台亞、福懋、統一精工，或自行輸入。中油用官方牌價；其他品牌優先採你在牌價生效後於該站的實付價，否則以中油牌價為參考 |
| 停車費 | 全台 21 縣市路邊停車費欠費查詢（停車單、催繳單、工本費、是否移送），輸入車牌與車種即可，不需驗證碼；可單查一縣市或一次查全台；可開啟每日自動檢查並列入首頁待辦 |
| 牌照稅 | 依排氣量與能源類型估算自用牌照稅（機車 150cc 以下與純電動車免徵），一鍵建立每年 4/30 的繳納提醒 |
| etag | 儲值／通行費記錄推算餘額，低於門檻列入待辦；官方餘額與欠費提供查詢入口 |

> 本系統**不發送任何通知**（無推播、Email、LINE 等）；提醒只以畫面上的待辦與狀態標籤呈現。

## 帳號與權限

1. **第一位註冊的使用者自動成為最高權限管理員**。新安裝時登入頁會直接顯示註冊表單。
2. 之後的註冊由管理員在「後台 → 安全」控制：`關閉`（預設）／`需核准`／`開放`。
3. 管理員可核准、停用、刪除使用者、重設密碼、設為或取消管理員、登出任一工作階段，並檢視登入與管理動作的稽核紀錄。
   **管理員無法看到其他使用者的車輛與記錄內容**；每位使用者的資料彼此隔離。
4. 系統一律保留至少一位啟用中的管理員，且不能降級或刪除自己。

### 防止被搶註冊（公網部署務必看）

服務一上公網，第一個註冊的人就是管理員。請在首次啟動前於 `.env` 設定 `MOTOQ_SETUP_TOKEN`，
第一位註冊時需輸入此設定碼。也可以不開放網頁註冊，改用 CLI 建立第一個帳號：

```bash
docker compose exec motoq python -m app.cli create-user --username <帳號>   # 第一位自動為管理員
```

## 部署（NAS Docker）

```bash
cp .env.example .env              # 設定 MOTOQ_SETUP_TOKEN；公網請保留 MOTOQ_COOKIE_SECURE=true
mkdir -p data && sudo chown 1000:1000 data
docker compose up -d --build
```

開啟 `http://<NAS>:8080`，再由反向代理對外提供 HTTPS（PWA 與 Secure cookie 需要 HTTPS）。

- 反向代理請轉送 `X-Forwarded-For` / `X-Forwarded-Proto`（登入限流與稽核紀錄用來辨識來源 IP）。
- 容器固定單一 worker，勿調高（排程在程序內執行，多 worker 會重複觸發）。
- 資料在 `./data/`：`motoq.db`、`uploads/`、`snapshots/`（匯入前自動快照）、`backups/`。
- 升級：`git pull && docker compose up -d --build`，啟動時會自動執行資料庫遷移。

### 備份與還原

```bash
./deploy/backup.sh                       # 產生 ./data/backups/motoq-backup-*.tar.gz，保留最近 14 份
AGE_RECIPIENT=age1... ./deploy/backup.sh  # 已安裝 age 時，額外加密並刪除明文檔
```

可放進 NAS 的排程（例如每天凌晨）。備份檔含資料庫快照與 `uploads/`。還原：

```bash
docker compose down
tar -xzf motoq-backup-YYYYmmdd-HHMMSS-xxxxxx.tar.gz -C data/   # 得到 motoq.db 與 uploads/
docker compose up -d
```

## 本機開發

```bash
# 後端
cd backend
uv sync
MOTOQ_DATA_DIR=./data uv run python -m app.cli create-user --username me
MOTOQ_DATA_DIR=./data uv run uvicorn app.main:app --reload --port 9155

# 前端（另一個終端機；/api 會代理到 9155）
cd frontend && npm install && npm run dev
```

或先 `npm run build`，再以 `MOTOQ_FRONTEND_DIST=../frontend/dist` 讓後端直接提供前端。
示範資料：`MOTOQ_DATA_DIR=./data-demo uv run python -m app.cli seed-demo`（登入資訊寫入 `data-demo/DEMO_LOGIN.txt`）。

維修履歷 PDF 需要系統安裝 Pango 與中文字型（Docker 映像已包含；macOS：`brew install pango`，並於執行時設定
`DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib`）。缺少時 PDF 端點回 501，仍可使用 HTML 版本以瀏覽器列印。

## 測試

```bash
cd backend && uv run pytest -q
```

涵蓋：油耗計算（充滿到充滿、部分加油、漏記、電量估算、異常警示）、保養預測（里程／時間先到、逾期、無日均里程）、
到期提醒（30/7/1 與自訂天數）、註冊與管理員規則、使用者資料隔離、油電車、附件 EXIF 移除與縮圖、
年度報告與兩車比較、匯出入（ID 重新配發與使用者範圍）、備份、排程、舊版資料庫升級。

## 計算規則

- **油耗**：充滿到充滿。兩次「加滿」之間距離 ÷ 其間（含後者）加入的量；未加滿的併入下一次加滿；標記「前次漏記」的區間不採計。
- **油電車**：km/L 只用加油記錄；插電充電的費用計入成本，但不影響 km/L。
- **電動車**：同樣充滿到充滿；充滿區間不足 2 個且有填電池容量與電量 % 時，改以（上次充後 % − 本次充前 %）× 電池容量估算。
- **異常警示**：最近 3 個區間的平均，低於其前 10 個區間平均達門檻（預設 15%）時警示；至少需 6 個區間。
- **保養**：每項可設 km 與月份間隔。里程到期日 = 今天 + 剩餘里程 ÷ 日均里程（近 90 天回歸，資料不足退回全期），
  與時間到期日取較早者；剩餘不到間隔 10% 為「即將到期」。
- **年度成本**：能源、保養維修、稅金、保險、檢驗規費、罰單、停車／其他；稅費以實際繳費日認列，罰單以違規日認列。
  每公里成本 = 總成本 ÷ 期間首末里程記錄之差。

## 已知限制

- **牌價來源**：只有中油提供開放資料。台塑、全國等品牌沒有公開 API，系統以中油牌價作為參考，
  並優先採用你自己在該站的實付單價；實際售價請以加油站為準。
- **停車費查詢**使用交通部「全國路邊停車費查詢 API」規範下各縣市政府的公開端點（官方限制每秒 1 次；系統已做間隔
  與 5 分鐘快取，每位使用者每小時最多 60 次）。臺中市官方僅提供 http（未加密），畫面會標示；新竹市端點在開發環境
  連線失敗。查詢僅供參考，繳費請至官方網站。
- **每日自動檢查預設關閉**：開啟後會把你車輛的車牌送到所選縣市政府的查詢服務，請自行決定。
- **違規罰單、etag 官方餘額、欠稅／燃料費查詢沒有只憑車牌的開放 API**（需身分證字號、車主證號與驗證碼），
  因此只提供官方入口與 CSV 匯入、手動記錄；`FineProvider` 介面保留。
- **牌照稅估算只涵蓋「自用」乘人小客車與機車**，營業用、貨車等稅額不同；燃料費（公路養管費）各來源金額不一，
  不做估算。稅額以官方公告與繳款書為準。
- 容器對外連線需要能連到 `vipmbr.cpc.com.tw` 與 `trafficapi.pma.gov.taipei`（TWCA 憑證）；連不上時這兩項功能會顯示錯誤，其他功能不受影響。
- **保養範本**為常見參考值，非原廠規範，請依車輛手冊調整。
- 匯入只支援 JSON，且為「取代你目前的全部資料」；匯出不含圖片檔案（請用備份）。
- 沒有「忘記密碼」信件流程（無 Email）；請管理員在後台重設，或在伺服器用 `reset-password` 指令。
- 數量與單價以浮點數儲存（金額為整數 TWD）。
- 不含 OCR、通知推播、控制台整合與 Google 日曆（依需求移除）。
